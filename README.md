# Radiant-love Healthcare Ltd.

A simple UK healthcare recruitment and staffing website inspired by the client's Top Hat Healthcare reference.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included
- Full-width recruitment agency homepage
- Jobs search with keyword, location and recruitment-service filters
- List/grid job results
- Individual job pages
- Who We Are
- What We Do
- For Employers / vacancy registration
- Submit Your CV
- Contact Us
- Supplied Radiant-love SVG logo component with default/reversed variants
- Official registered office shown in header/footer
- Unsplash imagery
